# SYSTEM CRASHER – Old-School Graphic Assets

Dieser Ordner ist fuer die Druck-/Xerox-Motive der Manifest-Grafiklandkarte vorbereitet.

Geplante Assets:

- `system-grid.svg` – Form / Raster / Kategorie
- `people-row.svg` – Menschen / diejenigen, die uebrig bleiben
- `cassette.svg` – Musik / Noise / Jugend / DIY
- `question-mark.svg` – Fragen / Widersprueche
- `broken-box.svg` – Schublade / aufgebrochene Form
- `arrow-x.svg` – Punk-Markierungen, Pfeile, X als Zusatzmotiv

Gestaltungsregel:
Motive bleiben hinter dem Text, abwechselnd links/rechts, teilweise angeschnitten und wie alte Siebdruck-/Xerox-Spuren behandelt.
