SYSTEM CRASHER – Polaroid-Fotos

Fotos in diesem Ordner ablegen und in photos.json einem Slot zuweisen.

Beispiel:

{
  "photo-slot-01": [
    {
      "file": "probe-01.jpg",
      "alt": "SYSTEM CRASHER im Proberaum",
      "caption": "Rehearsal noise"
    }
  ],
  "photo-slot-02": [],
  "photo-slot-03": []
}

Wenn ein Slot leer ist, wird er auf der Website vollständig verborgen.
Mehrere Fotos pro Slot sind möglich.

Empfohlene Formate: JPG oder WebP.
Dateinamen ohne Leerzeichen verwenden.
